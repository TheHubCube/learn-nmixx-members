# Learn the Faces of NMIXX (Learn who is whO.O)

A web-based guessing game for NSWERs and newcomers to learn and recognize the members of NMIXX!

## Game Modes
* **Classic:** Play through 6 rounds and try to get the highest score without losing all 4 hearts.
* **Endless:** Keep guessing through a shuffled deck of member photos until you run out of hearts. Tracks your personal best score!
* **JjyuKkyu Challenge:** *Be an expert in recognizing the Maknae Monsters!* A 10-round timed showdown (2m 05s) where you only choose between **Jiwoo** and **Kyujin**.

## How to Run
No build step or dependencies required. Simply clone the repository and open `index.html` in any browser, or host it directly via GitHub Pages.
